gurl

A curl-inspired HTTP client written in Go. It speaks curl's flags, so muscle memory works, and it shows you nicer output when you are looking at a terminal.

Install

curl -fsSL https://gurl.somosingogo.dev/install.sh | sh

Linux and macOS. The script downloads the right binary from GitHub Releases and checks its sha256. Set GURL_VERSION to pin a release, GURL_INSTALL_DIR to choose where it goes.

go install github.com/CSingogo/gurl/cmd/gurl@latest

Windows: download the .zip from GitHub Releases. Homebrew, apt and Arch packages are on the way.

Try it

This server runs gurl's test endpoints. Point gurl at it:

gurl gurl.somosingogo.dev/getgurl -sSL -o /dev/null -w '%{http_code} %{url_effective}\n' gurl.somosingogo.dev/redirect/3gurl --json '{"name":"gurl"}' gurl.somosingogo.dev/postgurl -i gurl.somosingogo.dev/status/418

When output goes to a terminal, gurl colors headers and indents JSON. Piped, written with -o, or with NO_COLOR or --raw set, the body is exactly what curl would print.

Test endpoints

/getEchoes the request: query, headers, caller address. /post, /put, /patch, /delete and /anything do the same and also parse form, multipart and JSON bodies.
/headersJust the request headers.
/ipYour IP address.
/user-agentYour User-Agent.
/status/{code}Replies with that status code (100 to 599).
/delay/{n}Waits n seconds (0 to 10), then answers like /get.
/bytes/{n}n random bytes, up to 1 MB. Add ?seed=N to make them repeatable.
/redirect/{n}Redirects n times (1 to 20), ending at /get.
/basic-auth/{user}/{pass}401 unless you send those credentials with -u.
/jsonA small JSON document.
/gzipA gzip-compressed JSON reply.

Fair use: requests are rate limited per IP, bodies are capped at 1 MB.
